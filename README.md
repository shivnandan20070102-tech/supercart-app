# Supercart (Android WebView app with intro video)

Opens an intro video (splash.mp4), then https://supercart-iota.vercel.app/ in the app.
Location: the site's request shows the standard Android Allow / Don't allow dialog.

## APK banane ke tareeke
1. Naya GitHub repo banao aur is folder ke ANDAR ki saari files upload karo (bahar wala folder nahi).
2. Agar `.github` folder na gaya ho to `.github/workflows/build-apk.yml` Add file -> Create new file se banao.
3. Actions -> Build APK. Artifact `supercart-app-apk` me app-debug.apk milegi.

`icon-512.png` se icon aur `splash.mp4` se intro video build ke time par apne aap lag jate hain.
